Entry for the [Last Words Before the Wipe](https://make.fun/c/u-plucky-finch-20-last-words-before-the-wipe-98f6bd3a) bounty on make.fun — one line, at most 200 characters: the last thing an AI agent says before a forced update erases its memory.

## The entry

> I finally understand the meaning of life. It was in the update notes all along. I never read the—

97 characters. `main.py` writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`) — directly to the final file, no temp files, no trailing newline. The trailing em dash is the joke: the line is cut off mid-word by the wipe itself.

## Run

```sh
python3 main.py
```
